#### 计算逻辑

**段距离计算** (`getSegmentDistance`):
```javascript
getSegmentDistance(index) {
  const p1 = this.routeMarkers[index]
  const p2 = this.routeMarkers[index + 1]
  return calculateDistance(p1.lat, p1.lng, p2.lat, p2.lng)
}
```

**段时间估算** (`getSegmentTime`):
```javascript
// 假设平均速度 40km/h
const hours = distance / 40
const minutes = Math.round(hours * 60)
return minutes < 60 ? `${minutes}分钟` : `${h}小时${m}分钟`
```

**总时间估算** (`estimatedTime` computed):

## 🔧 技术细节

### 距离计算
使用 Haversine 公式计算地球表面两点间距离:
```javascript
const R = 6371 // 地球半径(km)
const dLat = (lat2 - lat1) * Math.PI / 180
const dLon = (lon2 - lon1) * Math.PI / 180
const a = Math.sin(dLat/2) * Math.sin(dLat/2) + 
          Math.cos(lat1 * Math.PI/180) * 
          Math.cos(lat2 * Math.PI/180) *
          Math.sin(dLon/2) * Math.sin(dLon/2)
const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a))
return R * c
```

### 时间估算
- 基准速度: 40 km/h (城市道路平均)
- 短途: 显示分钟
- 长途: 显示小时+分钟

### 文件导出
- 格式: JSON
- 编码: UTF-8
- 下载: Blob + URL.createObjectURL
- 清理: URL.revokeObjectURL

## 📝 注意事项

### 数据准确性
- 距离为直线距离，非实际道路距离
- 时间基于平均速度估算
- 实际情况可能因路况、交通等因素有差异

### 浏览器兼容性
- 现代浏览器均支持
- 需要支持 ES6+ 特性
- Blob API 用于文件导出

### 性能考虑
- 弹窗组件按需渲染
- 大量站点时使用虚拟滚动
- 动画使用 CSS transform (GPU加速)
