# AI智能路线生成功能设计

## 功能概述
用户可以通过AI助手根据个人资料生成个性化旅行路线，并一键导入到路径规划模块。

## 实现流程

### 1. AI 生成路线
- 用户在AI助手中询问旅行建议
- AI根据用户的年龄、职业、旅行画像、偏好城市等信息
- 返回包含具体景点和时间安排的行程规划

### 2. 解析AI响应
从AI的回复中提取：
- 景点名称（如"故宫"、"颐和园"）
- 时间安排（第一天、第二天等）
- 景点描述

### 3. 查询景点坐标
- 调用后端景点搜索API
- 根据景点名称查询经纬度坐标
- 匹配数据库中的景点信息

### 4. 导入路径规划
- 将查询到的景点自动添加到 routeMarkers
- 切换到"路径规划"标签页
- 自动计算路线
- 在地图上展示完整路线

## 数据结构

### AI响应格式（期望）
```
第一天：故宫 - 天安门广场 - 王府井
第二天：颐和园 - 圆明园
第三天：八达岭长城
```

### routeMarker 格式
```javascript
{
  latitude: 39.9163,
  longitude: 116.3972,
  label: "故宫",
  source: "ai",  // 标记来源
  meta: {
    subtitle: "明清皇家宫殿",
    category: "历史文化"
  }
}
```

## 用户体验

1. **对话式生成**
   - 用户："为我推荐一个北京3日游行程"
   - AI：返回详细行程（包含景点、时间、说明）

2. **一键导入**
   - 在AI助手对话框显示"应用到路径规划"按钮
   - 点击后自动提取景点并导入

3. **可视化反馈**
   - 切换到路径规划标签
   - 在地图上标记所有景点
   - 显示连接线
   - 展示路线统计信息

4. **可编辑**
   - 用户可以删除不需要的景点
   - 可以调整顺序
   - 可以添加额外景点

## 优化点

1. **智能匹配**
   - 模糊匹配景点名称
   - 考虑城市上下文
   - 处理别名（如"故宫"="北京故宫"）

2. **错误处理**
   - 找不到坐标的景点提示用户
   - 部分成功时显示成功数量
   - 提供手动添加选项

3. **用户确认**
   - 显示将要导入的景点列表
   - 允许用户勾选/取消
   - 显示预计总距离和时间

4. **智能排序**
   - 根据AI建议的时间顺序排列
   - 或者使用路径优化算法
   - 考虑开放时间等因素
