# 🧪 AI路线生成 - 快速测试指南

## 🚀 快速启动

### 1. 启动后端
```cmd
cd c:\code\travel\backend
python app.py
```

### 2. 刷新前端
- 按 **Ctrl+F5** 强制刷新浏览器（清除缓存）

## ✅ 测试清单

### 测试1：AI回复不重复 ✓

**步骤**：
1. 点击右下角AI助手按钮
2. 输入："你好"
3. 观察回复

**预期结果**：
- ✅ 只显示一次"你好"的回复
- ✅ 控制台显示：`[Coze] ℹ️ Completed 事件 - 跳过`

**失败标志**：
- ❌ 显示两次相同内容
- ❌ 控制台显示多个 `✅ 发送内容`

---

### 测试2：提取景点并导入路径规划 ✓

**步骤**：
1. 在AI助手输入："为我推荐北京3日游"
2. 等待AI回复（可能需要30-60秒）
3. 点击AI消息下方的 **"应用到路径规划"** 按钮
4. 观察变化

**预期结果**：
- ✅ 自动切换到 **"路径"** 标签页
- ✅ 地图上显示多个蓝色景点标记
- ✅ 景点之间有红色路线连接
- ✅ 弹出提示："✅ 成功导入 X 个景点并规划路线！"
- ✅ 左侧显示路线统计（站点数、总距离等）

**失败标志**：
- ❌ 没有切换标签，还在AI助手
- ❌ 地图上看不到任何景点标记
- ❌ 没有路线显示
- ❌ 只显示"已识别X个景点"但没有实际导入

---

### 测试3：提取特殊格式的景点 ✓

**步骤**：
1. 在AI助手输入："给我一个详细的成都2日游行程，包含时间安排"
2. 等待AI回复（应该包含类似"8:00-10:00 宽窄巷子"的格式）
3. 点击 **"应用到路径规划"**

**预期结果**：
- ✅ 能识别出带时间段的景点（如："8:00-10:00 宽窄巷子" → 提取出"宽窄巷子"）
- ✅ 能识别出"第一天"、"第二天"等标题行，但不会把它们当作景点
- ✅ 正确导入所有景点到路径规划

**示例AI输出**：
```
第一天:
8:00-10:00 天安门广场
11:00-13:00 故宫
15:00-18:00 颐和园

第二天:
9:00-11:00 景山公园
13:00-14:00 北海公园
15:00-17:00 南锣鼓巷
```

**应该提取出**：天安门广场、故宫、颐和园、景山公园、北海公园、南锣鼓巷

## 🎯 快速问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| AI回复重复 | 前端缓存未清除 | Ctrl+F5 强制刷新 |
| 点击按钮无反应 | 事件监听器未生效 | 检查控制台错误，重启前端 |
| 地图上无标记 | 标签未切换到'route' | 检查 activeTab 值 |
| 无法识别景点 | AI输出格式不匹配 | 检查提取日志，可能需要调整正则 |
| 路线未自动计算 | planSimpleRoute未调用 | 检查是否有2个以上景点 |
| 后端500错误 | 数据库连接问题 | 检查MySQL是否运行 |

## 💡 测试技巧

1. **使用简单问题测试重复问题**
   - "你好" 或 "介绍一下你自己"
   - 回复短，容易看出是否重复

2. **使用明确的行程请求测试提取**
   - "推荐北京3日游"
   - "成都5日游行程"
   - 这些会返回具体景点名称

3. **观察控制台，不要只看界面**
   - 很多问题可以通过日志快速定位

4. **测试边界情况**
   - 只有1个景点（应提示至少需要2个）
   - 景点名称在数据库中不存在（应显示部分成功）
   - 网络中断时的行为
