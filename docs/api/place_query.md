## 一、接口概述

场所查询模块（Place Query API）用于根据用户位置、搜索半径与景点类别，  
返回指定范围内的景点列表。该模块是“个性化旅游系统”的核心数据接口之一，  
同时为推荐模块、路径模块、前端地图展示提供基础数据支持。

---

## 二、接口列表

| 接口名称 | 请求方式 | 路径 | 功能说明 |
|-----------|-----------|------|-----------|
| 获取邻近景点 | GET | `/api/places/nearby` | 根据经纬度与半径查询附近景点 |
| 获取景点详情 | GET | `/api/places/<id>` | 查询指定景点详细信息 |
| 获取类别列表 | GET | `/api/places/categories` | 获取系统支持的景点分类 |

---

## 三、接口定义

### 1️⃣ GET `/api/places/nearby`

#### 📘 功能描述
根据用户当前位置（纬度、经度），返回给定半径内的景点信息。  
可选参数支持类别过滤与分页控制。

#### 🧾 请求参数

| 参数名 | 类型 | 是否必填 | 默认值 | 说明 |
|--------|------|----------|--------|------|
| lat | float | ✅ | — | 用户当前纬度 |
| lon | float | ✅ | — | 用户当前经度 |
| radius | float | ❌ | 5.0 | 搜索半径（单位：km） |
| category | string | ❌ | 全部类别 | 景点类别（如“美食”、“自然”、“历史”等） |
| limit | int | ❌ | 20 | 最大返回结果数 |
| offset | int | ❌ | 0 | 分页偏移量 |

#### 📥 请求示例

```bash
GET /api/places/nearby?lat=39.9&lon=116.4&radius=5&category=景点&limit=10
