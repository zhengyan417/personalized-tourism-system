## 一、接口概述

旅游日记模块（Travel Diary API）允许用户创建、查看、修改与删除旅行日记，  
同时支持对日记内容进行**霍夫曼编码压缩存储**以节省数据库空间。  

该模块与景点表（`attractions`）和用户表（`users`）相关联，  
是系统中个性化记录与推荐算法的重要数据来源。

---

## 二、接口列表

| 接口名称 | 请求方式 | 路径 | 功能说明 |
|-----------|-----------|------|-----------|
| 创建日记 | POST | `/api/diaries` | 新建一篇旅游日记 |
| 获取用户日记列表 | GET | `/api/diaries` | 查询某用户的所有日记 |
| 获取单篇日记详情 | GET | `/api/diaries/<id>` | 查看指定日记 |
| 更新日记 | PUT | `/api/diaries/<id>` | 修改日记内容或标题 |
| 删除日记 | DELETE | `/api/diaries/<id>` | 删除指定日记 |

---

## 三、接口定义

### 1️⃣ POST `/api/diaries`

#### 📘 功能描述
创建新日记。  
后端在存储前会自动执行 **霍夫曼编码压缩算法**，将文本压缩为二进制存储。  

#### 🧾 请求体参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | int | ✅ | 用户ID |
| attraction_id | int | ❌ | 关联景点ID，可为空 |
| title | string | ✅ | 日记标题 |
| content | string | ✅ | 日记内容（原文） |

#### 📥 示例请求

```json
{
  "user_id": 1,
  "attraction_id": 2,
  "title": "颐和园游记",
  "content": "今天阳光很好，颐和园的湖面波光粼粼……"
}
