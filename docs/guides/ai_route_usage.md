# AI智能路线生成 - 使用指南

## 🎯 功能简介

用户可以通过与AI助手对话，让AI根据个人资料（年龄、职业、旅行画像、偏好城市）生成个性化旅行路线，并一键导入到路径规划模块。

## 🚀 使用步骤

### 步骤1：完善个人资料

1. 访问**个人中心页面** (`/profile`)
2. 填写以下关键信息：
   - ✈️ **旅行画像** - 例如："喜欢自然风光和历史文化，偏好慢节奏深度游"
   - 🏙️ **偏好城市** - 例如："北京,成都,杭州"
   - 💼 **职业、年龄** - 帮助AI理解你的需求
3. 点击"保存修改"

### 步骤2：与AI助手对话

1. 在任何页面，点击右下角的 **AI助手悬浮按钮**
2. 输入你的旅行需求，例如：
   ```
   ✅ "为我推荐一个北京3日游行程"
   ✅ "我想去成都玩5天，有什么好的行程安排？"
   ✅ "根据我的喜好，推荐一个周末旅行计划"
   ✅ "帮我规划杭州2日游，要包含历史文化景点"
   ```

3. AI会根据你的个人资料，返回详细的行程规划，例如：
   ```
   第一天：故宫 - 天安门广场 - 景山公园
   第二天：八达岭长城
   第三天：颐和园 - 圆明园
   ```

### 步骤3：一键导入到路径规划

1. 在AI助手的回复下方，找到 **"应用到路径规划"** 按钮
2. 点击按钮
3. 系统会自动：
   - ✅ 识别AI推荐的景点名称
   - ✅ 查询每个景点的精确坐标
   - ✅ 添加到路径规划模块
   - ✅ 切换到"路径规划"标签页
   - ✅ 在地图上标记所有景点
   - ✅ 自动计算最佳路线

4. 查看导入结果：
   - 成功提示会显示导入了多少个景点
   - 未找到坐标的景点会被跳过

### 步骤4：查看和编辑路线

导入完成后，在**路径规划**标签页，你可以：

1. **查看路线时间线**
   - 显示所有站点
   - 每个站点的名称和坐标
   - 来源标记（AI推荐）

2. **路线分析**
   - 站点数量
   - 连接段数
   - 总距离

3. **编辑路线**
   - 点击"撤销"删除最后一个点
   - 点击"反向"反转路线顺序
   - 点击"清空"清空所有站点
   - 手动在地图上添加更多站点

4. **路径优化**
   - 切换"智能优化模式"
     - 系统自动计算最优访问顺序
     - 第一个点为起点，其余按最短路径排序
   - 或使用"顺序访问模式"
     - 严格按照添加顺序规划路径

5. **计算路线**
   - 点击"计算路线"按钮
   - 查看详细的路线结果弹窗
   - 包含时间线、距离、预计时间

6. **导出路线**
   - 点击"导出路线"按钮
   - 下载JSON格式的路线文件
   - 可用于保存或分享

## 🔍 工作原理

### 1. 景点识别算法

系统使用多种模式匹配景点名称：

```javascript
// 模式1: "景点名：" 格式
// 例如："上午：故宫"

// 模式2: "- 景点名" 或 "* 景点名"
// 例如："- 颐和园"

// 模式3: "前往XX" "游览XX" "参观XX"
// 例如："前往八达岭长城"

// 模式4: 常见景点库匹配
// 例如：自动识别"故宫"、"长城"、"西湖"等
```

### 2. 坐标查询流程

```
景点名称 → 后端API搜索 → 数据库查询 → 返回坐标
                ↓
        精确匹配 或 模糊匹配
                ↓
        按相关度排序，返回最佳匹配
```

### 3. 路线导入流程

```
1. AI返回行程文本
   ↓
2. 提取景点名称（正则表达式）
   ↓
3. 批量查询坐标（API调用）
   ↓
4. 转换为routeMarker格式
   ↓
5. 添加到路径规划模块
   ↓
6. 更新地图显示
   ↓
7. 自动计算路线
```

```json
  "role": "assistant",
  "content": "第一天：故宫 - 天安门...\n第二天：..."
}
```

### 提取的景点列表
```javascript
["故宫", "天安门广场", "颐和园", "八达岭长城"]
```

```javascript
{
  "name": "故宫",

  "longitude": 116.3972,
  "category": "历史文化",
  "description": "明清两代的皇家宫殿"
```

```javascript
{
  "latitude": 39.9163,
  "longitude": 116.3972,
  "label": "故宫",
  "source": "ai",
  "meta": {
    "subtitle": "明清两代的皇家宫殿",
    "category": "历史文化"
  }

```

## ⚠️ 注意事项

### 1. 景点名称要准确
- ✅ 推荐："故宫"、"颐和园"、"八达岭长城"
- ❌ 避免："那个很有名的宫殿"、"北京的园林"

### 2. 可能无法识别的情况
- 非常规景点名称
- 拼写错误
- 过于笼统的描述

**解决办法：**
- 让AI提供更具体的景点名称
- 手动在地图上添加缺失的景点

### 3. 景点数量限制
- 单次最多识别 **15个景点**
- 如果AI推荐更多，只导入前15个
- 可以分批导入

### 4. 网络要求
- 需要连接到后端服务器
- 需要访问景点数据库
- AI助手需要访问Coze API

## 🛠️ 故障排除

### 问题1：点击按钮没有反应
**可能原因：**
- 浏览器控制台有错误
- 后端服务未启动

**解决方法：**
1. 按F12打开开发者工具
2. 查看Console标签的错误信息
3. 确认后端服务运行在 http://localhost:5000

### 问题2：提示"未能从AI回复中识别出景点"
**可能原因：**
- AI回复不包含景点名称
- 景点名称格式不标准

**解决方法：**
1. 重新询问AI，要求提供具体景点名称
2. 例如："请列出具体的景点名称，每行一个"

### 问题3：部分景点未导入
**可能原因：**
- 数据库中没有该景点
- 景点名称匹配失败

**解决方法：**
1. 查看成功提示中的数字
2. 手动在"路径规划"的搜索框添加缺失景点
3. 或者在地图上直接点击添加

### 问题4：路线顺序不合理
**解决方法：**
1. 使用"反向"按钮反转路线
2. 开启"智能优化模式"重新计算
3. 手动调整：清空后按理想顺序重新添加
