# 网络访问配置说明

## 问题描述
从局域网IP访问前端时，无法连接到后端API（登录失败等）。

## 解决方案

### 1. 前端修改（已完成）

**文件：`frontend/src/api/index.js`**
- 添加智能后端地址检测功能
- 当从网络IP访问时，自动将后端地址的 `localhost` 替换为当前主机名
- 例如：从 `http://192.168.1.100:8080` 访问时，后端地址自动变为 `http://192.168.1.100:5000`

**文件：`frontend/vue.config.js`**
- 添加 `host: '0.0.0.0'` 配置，允许从网络访问前端开发服务器

### 2. 后端修改（已完成）

**文件：`backend/app/__init__.py`**
- CORS 配置更新，支持局域网IP访问
- 允许的源包括：
  - `localhost:*`
  - `127.0.0.1:*`
  - `192.168.x.x:*` (常见局域网)
  - `10.x.x.x:*` (企业内网)
  - `172.16-31.x.x:*` (Docker等)

**文件：`backend/app.py`**
- 已配置为 `host='0.0.0.0'`，允许从网络访问

### 3. 使用说明

#### 获取本机局域网IP
**Windows PowerShell:**
```powershell
ipconfig | findstr IPv4
```

**Linux/Mac:**
```bash
ifconfig | grep "inet "
# 或
ip addr show
```

#### 访问方式

1. **本地访问（原有方式）：**
   - 前端：http://localhost:8080
   - 后端：http://localhost:5000

2. **局域网访问（新支持）：**
   - 前端：http://192.168.x.x:8080 （将x.x替换为你的IP）
   - 后端会自动匹配为：http://192.168.x.x:5000

3. **手机访问（同一WiFi）：**
   - 确保电脑和手机在同一局域网
   - 在手机浏览器输入：http://192.168.x.x:8080

### 6. 常见问题

**Q: 为什么从网络IP访问还是失败？**
A: 检查以下几点：
1. 确认后端服务已启动（检查 5000 端口）
2. 确认防火墙没有阻止 5000 和 8080 端口
3. 确认前端和后端都已重启

**Q: 如何检查端口是否开放？**
A: 
```powershell
# 检查 5000 端口（后端）
netstat -ano | findstr :5000

# 检查 8080 端口（前端）
netstat -ano | findstr :8080
```

**Q: 防火墙配置**
A: Windows 防火墙可能阻止网络访问，需要添加入站规则：
```powershell
# 允许 5000 端口（以管理员身份运行）
netsh advfirewall firewall add rule name="Backend API" dir=in action=allow protocol=TCP localport=5000

# 允许 8080 端口
netsh advfirewall firewall add rule name="Frontend Dev" dir=in action=allow protocol=TCP localport=8080
```

## 技术细节

### 智能地址匹配逻辑

```javascript
// frontend/src/api/index.js
function getSmartProdBase() {
  // 如果当前页面不是通过localhost访问
  if (hostname !== 'localhost' && hostname !== '127.0.0.1') {
    // 将后端地址中的localhost替换为当前主机名
    return envBase.replace('localhost', hostname)
  }
  return envBase
}
```

### CORS 动态验证

```python
# backend/app/__init__.py
def is_allowed_origin(origin):
    # 使用正则表达式匹配允许的IP范围
    allowed_patterns = [
        r'^http://localhost:\d+$',
        r'^http://192\.168\.\d+\.\d+:\d+$',
        # ... 更多模式
    ]
    return any(re.match(p, origin) for p in allowed_patterns)
```
